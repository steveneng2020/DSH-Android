# DSHA v1.4 20261111@0.2.2-rc.1. build20050357

本版以 DSHA 上游 0.2.2（上游 build357）为新基座重建，内置 DSH 0.2.2-rc.1，Ubuntu 基础环境仍为 10。

- 修复升级后启动页空白、点「启动 DSHA」无反应，以及偶发卡在恢复页的问题。
- 修复维护流程永久卡在「停止 Web 与终端任务」且点「重试」无效：停止屏障原先认不出本应用自己拉起的容器 supervisor，把它当成未识别进程一直不放行。
- 修复升级、降级 APK 后旧实例永久停在「身份未知」而无法启动：新增换代判据，安装包换代判为确定性过期并进入安装与修复页，不再挂起。
- 新增自动适配推理档位：为未声明推理档位的模型补齐声明（DSHA 不猜测第三方模型支持哪些档位，未声明即不显示推理等级），只增不改，写入前自动备份配置。
- 应用图标可点击切换，提供六套配色，切换后立即生效并记住选择；关于页与关于对话框的图标同源，点图标即可切换，图标改为充满画布。
- 切换图标后的提示改为对话框内的内联提示条，不再用浮在屏幕底部的 Toast：提示条随所选配色显示图标与文案，2.6 秒后自动收起；同时把六套图标的列表改为可滚动并给提示条留出固定最小高度，窄屏上不再被压成一条细缝。
- 修复「关于」页切换图标后闪退：切换回调原先直接取页面上下文，页面已切走时会抛异常导致进程退出；现改为取不到上下文就静默放弃刷新。
- 插件能力提示新增原生依赖体检：只读检查插件自带原生模块的 ABI 与文件头，不兼容时提示但不阻止安装。
- 新增更新日记面板：关于页按版本分块展示，可展开全部；「关于 DSHA」对话框内也内联同一份更新日记。
- 新增上游对比：显示与上游代码是否一致，只读不写回。
- 关于页交流入口改为联系邮箱 steveneng@163.com；更新页「在浏览器查看发布页」与稳定版、预览版链接指向本仓库，不再跳转上游发布页。
- 发行身份保持独立：包名 dsh.android.dev、自有发布证书，与上游 dsh.android.client 互不通用，覆盖安装需同签名。
- 单变体：移除兼容线与 GeckoView，只发布 Standard（Android 11 及以上、arm64-v8a、系统 WebView）。
- 合并上游 DSHA 0.2.2（上游 build357），内置 DSH 0.2.2-rc.1、Ubuntu 基础环境 10：含移动界面 v5、设备能力授权页独立成页、维护期插件注册死锁修复，以及上一次合并（上游 v0.2.1-rc.2，上游 build190）以来上游的全部提交。以真实上游提交（5e2dca92，2026-11-11）为祖先重建分支，后续上游更新可直接 merge，不再需要硬拼。
