# DSHA v1.5 20261113@0.2.2-rc.1・ build20070357

- 업데이트 페이지 상단과 파일 관리자의 앱 아이콘이 색상 구성표를 따르지 않던 문제를 수정했습니다. 이전에는 옛 기본 이미지가 고정되어 있어 아이콘을 바꿔도 그 두 곳은 그대로였습니다.

- "업데이트 확인"이 항상 "업데이트 없음"으로 나오던 문제를 고쳤습니다. 버전 이름 검사가 공백과 @를 허용하지 않는 상류 정규식을 그대로 물려받았는데, 이 프로젝트의 이름은 `v1.5 20261112@0.2.2-rc.1` 입니다. 자체 배포본이 자체 검사에서 조용히 버려지고 있었습니다.
- 업데이트 목록 읽기에 재시도를 추가했습니다. 시간 초과는 이미 있었지만(연결 15초 / 읽기 30초), 한 번의 통신 끊김에도 수동으로 다시 눌러야 했습니다. 최대 3회, 1초 / 2초 대기, 일시적 네트워크 오류에만 적용하며 인증서와 형식 오류는 재시도하지 않습니다.
- 안전 모드에서 플러그인 설치와 활성화를 차단합니다. 이전에는 배너 표시만 바꿀 뿐 실제로는 설치와 활성화가 가능해 의미가 없었습니다. 비활성화와 삭제는 계속 허용됩니다.
- 웹 세대가 바뀐 뒤 진입 버튼이 "여는 중…"에 멈추던 문제를 고쳤습니다. 세대가 바뀌었다는 것은 기다리던 세대가 사라졌다는 뜻입니다. 실패가 아니라 재시도 가능 상태로 되돌리고 "웹이 다시 시작되었습니다. 다시 열어 주세요"를 표시합니다.
- 가상 화면에 연속 프레임 거부 완화를 추가했습니다. 간헐적 거부는 정상이지만 3회 연속은 프레임 번호가 실제 화면과 어긋났다는 신호입니다. 오래된 세션을 버리고 다시 만듭니다.
- 업데이트 기록 대화상자가 "이 설치에는 현재 빌드의 업데이트 설명이 없습니다"로 표시되던 문제를 고쳤습니다. 제목 생성 쪽 구분자를 바꾼 뒤에도 읽는 쪽은 예전 형식으로 대조하고 있었습니다.
