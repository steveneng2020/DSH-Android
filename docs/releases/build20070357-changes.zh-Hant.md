# DSHA v1.5 20261113@0.2.2-rc.1・ build20070357

本版在 v1.4 基礎上修復分隔符顯示與更新檢查，並補齊 4 項上游缺失的健壯性能力。

- 修復更新頁頂部與檔案管理器裡的應用圖示不跟隨配色切換：原先寫死了舊版預設圖，換圖示後那兩處仍顯示舊圖案。
- 版本號分隔符統一為全角中點「・」：原先用實心圓點，字形天生偏下，與兩側數字不在同一條視覺中線上；換字元比修字形更可靠，不再依賴任何基線偏移 hack。
- 修復「檢查更新」永遠顯示暫無更新：更新清單的版本號驗證原先繼承上游正則，不允許空格與 @，而本專案版本號形如 `v1.5 20261112@0.2.2-rc.1`，導致自己發佈的更新包被自己的驗證丟棄且無任何報錯。
- 更新清單讀取新增重試：逾時原本已有（15s 連線 / 30s 讀取），但一次網路抖動就得手動再點；現在最多 3 次、退避 1s/2s，只對瞬时網路錯誤重試，憑證與清單格式錯誤不重試。
- 安全模式新增攔截外掛安裝與啟用：舊實作裡安全模式只影響橫幅顯隱，實際仍能裝/啟外掛，等於失效；停用與解除安裝不攔。
- 修復網頁換代後進入按鈕可能永久停在「進入中…」：代次變化說明等待的那一代已作廢，現在復位為可重試並提示「Web 已重啟，請重新進入」，不再誤判為失敗。
- 虛擬螢幕新增連續幀拒絕防抖：幀門偶發拒絕是正常的，但連續 3 次說明會話幀序號已與實際畫面脫節，此時丟棄舊會話重建，避免使用者點了沒反應。
- 修復更新記錄對話框顯示「本安裝包未附目前版本的更新說明」：標題產生器改成新分隔符後，讀取側仍按舊格式比對，導致更新日記被判為不屬於目前版本。
