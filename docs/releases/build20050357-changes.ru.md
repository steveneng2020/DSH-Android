# DSHA v1.4 20261111@0.2.2-rc.1. build20050357

Эта сборка пересобрана на upstream DSHA 0.2.2 (upstream build357) с DSH 0.2.2-rc.1 на базе Ubuntu 10.

- Исправлен пустой экран запуска после обновления, неработающая кнопка «Запустить DSHA» и редкие зависания на экране восстановления.
- Исправлено вечное зависание обслуживания на шаге «остановить Web и терминальные задачи», когда кнопка «Повторить» не помогала: барьер остановки не распознавал контейнерный supervisor, запущенный самим приложением, и считал его неопознанным процессом.
- Исправлено состояние «идентичность неизвестна» после обновления или отката APK: добавлен критерий смены сборки, который распознаёт замену пакета как определённое устаревание и ведёт на экран установки и восстановления.
- Добавлена автоматическая адаптация уровня рассуждений: моделям без объявленного уровня он прописывается (DSHA не угадывает, какие уровни поддерживает сторонняя модель; без объявления уровень не показывается). Только добавление, с автоматическим резервным копированием конфигурации.
- Значок приложения переключается нажатием, шесть цветовых схем, изменение действует сразу и запоминается; значок на странице «О программе» и в диалоге общий, нажатие открывает переключатель, значок заполняет всю область.
- Уведомление после смены значка теперь выводится встроенной строкой внутри диалога, а не всплывающим Toast внизу экрана: строка показывает значок и текст выбранной схемы и скрывается через 2,6 с. Список из шести строк стал прокручиваемым, а строка получила фиксированную минимальную высоту, поэтому на узких экранах больше не сжимается в полоску.
- Исправлено падение после смены значка на странице «О программе»: обратный вызов требовал контекст страницы, который бросает исключение, если страница уже закрыта, и ронял процесс; теперь при отсутствии контекста обновление просто пропускается.
- В подсказках о возможностях плагинов появилась проверка нативных зависимостей: только чтение ABI и заголовка файла нативных модулей плагина, предупреждение без блокировки установки.
- Добавлена панель журнала обновлений: страница «О программе» показывает версии блоками с возможностью раскрыть все; в диалоге «О DSHA» тот же журнал встроен.
- Добавлено сравнение с upstream: показывает, отличается ли код от upstream, только чтение, без записи.
- Раздел обратной связи заменён на адрес steveneng@163.com; ссылки «посмотреть релизы в браузере» и переключатели stable/preview ведут в этот репозиторий, а не на страницу релизов upstream.
- Идентичность релиза независима: пакет dsh.android.dev и собственный сертификат, несовместим с upstream dsh.android.client, для установки поверх нужна та же подпись.
- Единственный вариант: линия совместимости и GeckoView удалены, публикуется только Standard (Android 11+, arm64-v8a, системный WebView).
- Слияние с upstream DSHA 0.2.2 (upstream build357), включает DSH 0.2.2-rc.1 и базу Ubuntu 10: мобильный интерфейс v5, отдельная страница разрешений возможностей устройства, исправление взаимной блокировки регистрации плагинов при обслуживании и все коммиты upstream после предыдущего слияния (upstream v0.2.1-rc.2, upstream build190). Ветка пересобрана на реальном коммите upstream (5e2dca92, 2026-11-11), поэтому дальнейшие обновления сливаются напрямую.
