# DSHA v1.5 20261113@0.2.2-rc.1・ build20070357

本版在 v1.4 基础上修复分隔符显示与更新检查，并补齐 4 项上游缺失的健壮性能力。

- 修复更新页顶部与文件管理器里的应用图标不跟随配色切换：原先写死了旧版默认图，换图标后那两处仍显示旧图案。
- 版本号分隔符统一为全角中点「・」：原先用实心圆点，字形天生偏下，与两侧数字不在同一条视觉中线上；换字符比修字形更可靠，不再依赖任何基线偏移 hack。
- 修复「检查更新」永远显示暂无更新：更新清单的版本名校验原先继承上游正则，不允许空格与 @，而本项目版本名形如 `v1.5 20261112@0.2.2-rc.1`，导致自己发布的更新包被自己的校验丢弃且无任何报错。
- 更新清单读取新增重试：超时原本已有（15s 连接 / 30s 读取），但一次网络抖动就得手动再点；现在最多 3 次、退避 1s/2s，只对瞬时网络错误重试，证书与清单格式错误不重试。
- 安全模式新增拦截插件安装与启用：旧实现里安全模式只影响横幅显隐，实际仍能装/启插件，等于失效；禁用与卸载不拦。
- 修复网页换代后进入按钮可能永久停在「进入中…」：代次变化说明等待的那一代已作废，现在复位为可重试并提示「Web 已重启，请重新进入」，不再误判为失败。
- 虚拟屏新增连续帧拒绝防抖：帧门偶发拒绝是正常的，但连续 3 次说明会话帧序号已与实际画面脱节，此时丢弃旧会话重建，避免用户点了没反应。
- 修复更新记录弹窗显示「本安装包未附当前版本的更新说明」：标题生成器改成新分隔符后，读取侧仍按旧格式匹配，导致更新日记被判为不属于当前版本。
