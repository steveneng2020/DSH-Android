# DSHA v1.4 20261111@0.2.2-rc.1. build20050357

이 빌드는 업스트림 DSHA 0.2.2(upstream build357)를 새 베이스로 재구성했으며, DSH 0.2.2-rc.1과 Ubuntu 베이스 10을 포함합니다.

- 업데이트 후 시작 화면이 비어 있거나 「DSHA 시작」을 눌러도 반응이 없고, 복구 화면에서 멈추는 문제를 수정했습니다.
- 유지보수가 「Web 및 터미널 작업 중지」에서 영구히 멈추고 「재시도」도 듣지 않던 문제를 수정했습니다. 중지 장벽이 앱이 직접 띄운 컨테이너 supervisor를 인식하지 못해 미확인 프로세스로 처리했습니다.
- APK 업그레이드·다운그레이드 후 이전 인스턴스가 「신원 미확인」 상태로 남아 시작되지 않던 문제를 수정했습니다. 빌드 교체 판정을 추가해 패키지 교체를 확정적 만료로 처리하고 설치 및 복구 화면으로 넘어갑니다.
- 추론 수준 자동 적응을 추가했습니다. 추론 수준을 선언하지 않은 모델에 선언을 채웁니다(DSHA는 서드파티 모델이 어떤 수준을 지원하는지 추측하지 않으며, 미선언이면 수준을 표시하지 않습니다). 추가만 하며, 쓰기 전에 설정을 자동 백업합니다.
- 앱 아이콘을 눌러 전환할 수 있습니다. 6가지 배색을 제공하며 전환은 즉시 적용되고 기억됩니다. 「DSHA 정보」 페이지와 대화상자의 아이콘은 동일하며, 아이콘을 누르면 전환기가 열리고 아이콘이 영역을 가득 채웁니다.
- 플러그인 기능 안내에 네이티브 의존성 점검을 추가했습니다. 플러그인에 포함된 네이티브 모듈의 ABI와 파일 헤더를 읽기 전용으로 검사하고, 호환되지 않으면 설치를 막지 않고 경고합니다.
- 업데이트 일지 패널을 추가했습니다. 「DSHA 정보」 페이지에서 버전별로 나누어 표시하고 모두 펼칠 수 있으며, 「DSHA 정보」 대화상자에도 같은 일지를 표시합니다.
- 업스트림 비교를 추가했습니다. 코드가 업스트림과 같은지 표시만 하며 읽기 전용입니다.
- 교류 창구를 연락 이메일 steveneng@163.com으로 변경했습니다. 업데이트 페이지의 「브라우저에서 릴리스 보기」와 stable·preview 링크는 이 저장소를 가리키며 업스트림 릴리스 페이지로 가지 않습니다.
- 릴리스 신원은 독립적입니다. 패키지명 dsh.android.dev, 자체 릴리스 인증서를 사용하며 업스트림 dsh.android.client와 호환되지 않고, 덮어 설치에는 같은 서명이 필요합니다.
- 단일 변형: 호환 라인과 GeckoView를 제거하고 Standard만 배포합니다(Android 11 이상, arm64-v8a, 시스템 WebView).
- 업스트림 DSHA 0.2.2(upstream build357)를 병합했습니다. DSH 0.2.2-rc.1, Ubuntu 베이스 10을 포함하며 모바일 UI v5, 기기 기능 권한 페이지 분리, 유지보수 중 플러그인 등록 교착 수정, 이전 병합(upstream v0.2.1-rc.2, upstream build190) 이후 업스트림의 모든 커밋을 담았습니다. 실제 업스트림 커밋(5e2dca92, 2026-11-11)을 조상으로 브랜치를 재구성해 이후 업스트림 업데이트를 바로 병합할 수 있습니다.
