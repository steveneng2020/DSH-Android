# DSHA v1.4 20261111@0.2.2-rc.1・ build20050357

本版以 DSHA 上游 0.2.2（上游 build357）為新基座重建，內建 DSH 0.2.2-rc.1，Ubuntu 基礎環境仍為 10。

- 修復升級後啟動頁空白、點「啟動 DSHA」無反應，以及偶發卡在恢復頁的問題。
- 修復維護流程永久卡在「停止 Web 與終端任務」且點「重試」無效：停止屏障原先認不出本應用程式自己拉起的容器 supervisor，把它當成未識別行程一直不放行。
- 修復升級、降級 APK 後舊實例永久停在「身分未知」而無法啟動：新增換代判據，安裝包換代判為確定性過期並進入安裝與修復頁，不再掛起。
- 新增自動適配推理檔位：為未宣告推理檔位的模型補齊宣告（DSHA 不猜測第三方模型支援哪些檔位，未宣告即不顯示推理等級），只增不改，寫入前自動備份設定。
- 應用圖示可點擊切換，提供六套配色，切換後立即生效並記住選擇；關於頁與關於對話框的圖示同源，點圖示即可切換，圖示改為充滿畫布。
- 切換圖示後的提示改為對話框內的內嵌提示列，不再使用浮在螢幕底部的 Toast：提示列隨所選配色顯示圖示與文字，2.6 秒後自動收起；同時把六套圖示的清單改為可捲動並給提示列留出固定最小高度，窄螢幕上不再被壓成一條細縫。
- 修復「關於」頁切換圖示後閃退：切換回呼原先直接取頁面內容，頁面已切走時會拋出例外導致進程結束；現改為取不到內容就靜默放棄刷新。
- 外掛能力提示新增原生依賴體檢：唯讀檢查外掛自帶原生模組的 ABI 與檔案標頭，不相容時提示但不阻止安裝。
- 新增更新日記面板：關於頁按版本分塊展示，可展開全部；「關於 DSHA」對話框內也內聯同一份更新日記。
- 新增上游對比：顯示與上游程式碼是否一致，唯讀不寫回。
- 關於頁交流入口改為聯絡信箱 steveneng@163.com；更新頁「在瀏覽器檢視發布頁」與穩定版、預覽版連結指向本儲存庫，不再跳轉上游發布頁。
- 發行身分保持獨立：套件名 dsh.android.dev、自有發布憑證，與上游 dsh.android.client 互不通用，覆蓋安裝需同簽章。
- 單變體：移除相容線與 GeckoView，只發布 Standard（Android 11 以上、arm64-v8a、系統 WebView）。
- 合併上游 DSHA 0.2.2（上游 build357），內建 DSH 0.2.2-rc.1、Ubuntu 基礎環境 10：含行動介面 v5、裝置能力授權頁獨立成頁、維護期外掛註冊死鎖修復，以及上一次合併（上游 v0.2.1-rc.2，上游 build190）以來上游的全部提交。以真實上游提交（5e2dca92，2026-11-11）為祖先重建分支，後續上游更新可直接 merge，不再需要硬拼。
